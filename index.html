Personal project

Testing Factory: an AI agent for QA.

I designed and built an AI agent, powered by Claude, that turns a Jira user story or bug into tests that are written, automated, run and reported. The agent does the work and runs on its own on GitHub Actions. A QA lead supervises every step.

You write itDone by the AI agent
  1. 1User story / bugcreated in Jira
  2. 2Test planscope & risks
  3. 3Xray testswith steps
  4. 4GherkinBDD scenarios
  5. 5Playwright codeTypeScript
  6. 6Runreal browser
  7. 7ReportSlack, PDF + video

Automated from ticket to report, with every result linked back to the requirement in Jira and Xray.

HUMAN ON THE LOOP

Every test is reviewed by a QA

A reviewer validates or rejects each generated test in Jira. The agent reads the rejection comment and fixes the test on its next run.

BUG TRIAGE

No false bug reaches developers

When a test fails, the agent sorts it: real defect, test to fix, or flaky. It drafts the bug with steps, screenshot and video, and a QA confirms it.

PRODUCT OWNER

Vague story? The agent asks

If acceptance criteria are missing, the agent asks the PO in the Jira ticket and writes the tests from the answer.

GUARDRAILS

Kill switch and safety limits

One switch pauses the agent. A cap on tickets per run stops it and alerts the team on Slack.

ALWAYS ON

Runs on its own with GitHub Actions

Scheduled GitHub Actions workflows run the agent with no one at the keyboard: they watch Jira every hour, create missing tests every day, and post a summary after each run.

MEASURED

Weekly digest every Monday

Tests created, share reviewed by a QA, rejections and flaky tests. Rejection reasons feed back into the method.
